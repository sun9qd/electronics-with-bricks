## 🚀 How Can I Contribute?



### Reporting Bugs \& Requesting Features

* Check the **Issues** tab to see if your bug or feature request has already been reported.

* If not, open a new issue. Please provide a clear description, steps to reproduce (if applicable), and any relevant screenshots or error messages.



### Submitting a Pull Request (PR)

1. Fork the repository and create your branch from `main`.

2. If you've added software code, please ensure it compiles without errors.

3. If you've modified hardware (KiCad/OpenSCAD), please update the corresponding export files (e.g., Gerber or STL) if applicable.

4. Open the Pull Request with a clear description of your changes.



Thank you for supporting this project and keeping the maker community thriving!
